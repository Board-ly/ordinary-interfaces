# Code of Conduct

## The short version

Argue with the number, not the person who wrote it.

## What is expected

- **Bring evidence.** Disagreement here is settled by sources, not by seniority
  or by how confidently something is stated.
- **Assume the other person read the same spec differently.** Most conflicts in
  this repository are two correct readings of an ambiguous clause. Say which
  clause.
- **Accept "no" on scope.** This project deliberately holds thresholds and not
  taste. A rejected aesthetic rule is a scope decision, not a judgement of you.
- **Be plain.** Terse is fine. Dismissive is not.

## What is not

Harassment, personal attacks, demeaning comments, sustained disruption of
discussions, publishing anyone's private information, or unwelcome attention of
any kind. This applies in issues, pull requests, commit messages, and anywhere
else this project is being discussed.

## Enforcement

Report anything that crosses the line to **finn.m.garrels@gmail.com**. Reports
stay private. Maintainers will respond, and may edit, hide, or delete
contributions, or block accounts, when conduct warrants it. Maintainers are held
to the same standard as everyone else; a maintainer who breaks these rules is a
problem for the project, not an exception to it.

For a fuller framework, [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
is the standard text and this document is compatible with it.
